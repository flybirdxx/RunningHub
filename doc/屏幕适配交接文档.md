# 屏幕适配交接文档

更新时间：2026-06-16
分支：`feature/kmp-refactoring`

## 当前状态

本轮已在 `composeApp` 引入移动端屏幕适配基础设施，并已覆盖推送到远端分支。当前远端基线包含以下内容：

- `RhWindowInfo` / `LocalRhWindowInfo`：统一提供宽高断点、内容最大宽度、网格卡片最小宽度、底部面板高度比例等信息。
- `RunningHubPreviewSurface`：用于按 320、360、430、600、840、横屏、字体缩放等尺寸做 Compose Preview。
- 主导航 compact 模式底栏修复：`Scaffold(Modifier.fillMaxSize())` 保证底栏锚定到底部，避免被内容高度或 inset 异常撑到屏幕中部。
- 发现、社区、登录、详情、搜索、个人页、快捷创作、调优面板等页面已接入适配约束或补充 Preview。
- 补齐远端缺失的编译支撑：`WindowSizeClass`、`AppBarLogo`、`TaskHistoryScreenModel`、仓储接口方法、主题 token、`SmartAsyncImage.shape` 参数等。

## 注意事项

- 当前分支曾按要求执行覆盖推送，远端 `feature/kmp-refactoring` 已被本地分支状态更新。
- 不要再把底部导航内容区直接套 `navigationBarsPadding()` 后使用 `heightIn(min = ...)`，否则在部分设备或 Preview 宿主下可能把 bottom bar 撑高，造成图标悬在中部。
- `RunningHubPreviewSurface` 只用于单页面断点预览，不应用来包运行态 App 根导航。
- 新增页面若需要屏幕适配，应优先读取 `LocalRhWindowInfo.current`，不要在页面内重复硬编码宽度断点。
