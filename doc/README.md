## 使用规则

- 日常架构判断优先读取根目录 `ARCHITECTURE.md` 和 `DEVELOPMENT.md`。
- 接口字段、请求路径或产品资料需要证据时，再读取本目录对应文件。
- 迁移验收源在门禁解除前不得移动；封板后再按 `docs/archive/migration-2026/README.md` 的条件归档。
- 本目录不再新增阶段性 PRD、进度报告、移交记录或临时设计草稿。
