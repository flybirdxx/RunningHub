# Legacy Documentation Archive 2026-06-25

本目录保存 2026-06-25 文档整理时移出的过早或过旧材料，目标是避免后续 AI 任务把历史草稿误读为当前事实。

## 归档范围

- `root/`：根目录旧复核文档和旧快捷创作接口 docx。
- `doc/`：旧 PRD、KMP 重构草案、QuickCreate 阶段计划、进度报告、移交稿、网页抓取快照、早期 UI/架构/适配设计文档。
- `docs/plans/`：已不作为当前执行入口的计划和 HTML mockup。
- `docs/superpowers/`：早期 Superpowers 规格、实施计划和线框素材。

## 保留在当前位置的文档

- `ARCHITECTURE.md`、`DEVELOPMENT.md` 和 `AGENTS.md` 仍是当前开发入口。
- `docs/governance/`、`docs/adr/`、`docs/migration/` 仍由治理或迁移门禁引用。
- `doc/RunningHub-KMP-架构迁移验收标准.md` 仍被迁移门禁直接引用，暂不归档。
- `doc/` 下接口资料仍可能作为 API 字段和产品资料来源，详见 `doc/README.md`。

## 使用规则

归档文档中的相对路径保留归档前写法，可能已经不再指向当前文件位置。需要引用归档内容时，应同时说明它是历史材料，并用当前代码、当前文档入口或最新接口证据复核。
