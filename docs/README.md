# RunningHub Documentation Index

本文档是仓库文档入口索引，用于避免 AI 任务默认加载过期 PRD、阶段计划和历史抓取材料。

## 默认读取

- `ARCHITECTURE.md`：当前有效架构、模块边界和运行期装配。
- `DEVELOPMENT.md`：日常验证命令、PR 交付信息和治理入口。
- `docs/governance/long-term-priorities.md`：长期治理优先级和本地门禁映射。
- `docs/governance/ai-task-template.md`：AI 任务启动边界和验收字段。
- `docs/governance/chinese-commenting.md`：中文注释规则。
- `doc/README.md`：仍保留在 `doc/` 下的接口资料清单。

## 按需读取

- `docs/adr/`：已生效的架构决策记录。
- `docs/governance/`：长期治理、发布、性能、日志、文案资源化和契约测试说明。
- `docs/migration/`：仍被 L1 迁移门禁或迁移状态引用的活动证据；仅追溯 Gate/AC 时读取。
- `docs/scrape/`：带日期的数据抓取结果；使用前必须确认日期和数据来源是否仍有效。
- `docs/design/`：设计草稿和素材；除非任务明确要求设计追溯，否则不作为当前实现事实来源。

## 归档读取

- `docs/archive/migration-2026/`：迁移封板后的历史材料归档边界。
- `docs/archive/legacy-docs-2026-06-25/`：旧 PRD、早期方案、阶段进度、移交稿、抓取快照和过期设计文档。

归档材料保留原始上下文，不代表当前仓库状态。引用归档材料前，应优先核对当前代码、当前入口文档和门禁配置。
